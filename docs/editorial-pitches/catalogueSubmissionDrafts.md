### Project and public-good fit

Authier is an inspectable password-manager project spanning browser extensions,
a web vault, a mobile client, and its backend. It is intended to make unique
credentials, TOTP codes, and explicit approval of new devices easier to use
while keeping its implementation open for review and contribution.

The project is early-stage and has not published an independent third-party
security audit. The public security page documents the architecture and current
limitations, and the project advises people to evaluate mature alternatives
when audit history and long operational experience are requirements.
