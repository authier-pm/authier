Hi Medevel team,

I maintain Authier and would like to suggest it for editorial consideration as an open-source privacy project:

https://www.authier.pm/

Authier is an early-stage AGPL-3.0-or-later password manager for credentials and TOTP codes. It provides a web vault plus extensions for Chrome, Firefox, Edge, and Firefox for Android. Vault items are encrypted in the browser before synchronization. Accounts can require an existing approved device to review a new device request, or choose immediate enrollment for convenience.

Source: https://github.com/authier-pm/authier
Security model and limitations: https://www.authier.pm/security
Downloads: https://www.authier.pm/download

An important caveat for any coverage: Authier has not published an independent third-party security audit and has a much shorter operational history than established password managers. For high-impact secrets, readers should weigh that maturity gap and consider established independently audited options.
