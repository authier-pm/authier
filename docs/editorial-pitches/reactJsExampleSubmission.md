Hello React.js Examples,

I maintain Authier and would like to suggest it for independent review as an

Authier is an early-stage password manager and TOTP vault for browsers and the
web. Its shipped web vault and browser-extension interfaces use React 19 and
TypeScript. Vault records are encrypted in the client before synchronization,
and a new device can be held pending until an existing trusted device approves
it.

- Project: Authier
- Live site: https://www.authier.pm/
- Source and setup instructions: https://github.com/authier-pm/authier
- Downloads: https://www.authier.pm/download
- Security model and limitations: https://www.authier.pm/security
- Stack: React 19, TypeScript, React Router, Vite, tRPC, and Elysia
