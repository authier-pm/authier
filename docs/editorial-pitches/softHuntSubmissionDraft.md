### Description

Authier is an early-stage AGPL-3.0-or-later password manager for login
credentials and TOTP codes. Its browser extensions and web vault encrypt vault
items in the client before synchronization, support browser autofill, and can
require an existing trusted device to approve a new browser. The independent
open-source project is maintained from Czechia. It is not being submitted as an
EU-owned company, EU-only-hosted service, or documented self-hostable
deployment. The free tier does not expire, and optional monthly capacity packs
increase storage. Authier has not undergone an independent security audit.

### Data-collection disclosure

Authier processes email and account identifiers; vault payloads encrypted by the
client before synchronization; device and security metadata such as device
identifiers, platform, approval state, recent IP address and approximate network
location; autofill-field metadata such as hostname, query-stripped page URL,
field type and selector; and subscription, support, diagnostic and usage data.
It uses essential browser storage and providers including Cloudflare, Stripe,
Firebase, error-monitoring and email-delivery services. Providers may process
data outside a user's country under applicable safeguards. Authier does not sell
personal information or use vault content for advertising. Full policy:
https://www.authier.pm/privacy-policy

## Backlink caveat

SoftHunt says ordinary Developer accounts and submissions are free and normally
reviewed in 24–48 hours. Its published product pages are robots-allowed and
sitemap-listed, and a live non-EU-verified precedent exposes direct outbound
anchors without restrictive `rel` values after JavaScript hydration. However,
the raw product HTML contains no external product anchor and incorrectly
canonicalizes to `/products/`; the correct canonical and backlink appear only
after client/API hydration. The catalogue currently contains only three
published products. Treat this as a legitimate discovery listing, but do not
count its backlink toward DR unless Ahrefs actually discovers the published
Authier page.
